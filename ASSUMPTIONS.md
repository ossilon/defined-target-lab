# Assumptions register

This register lists every input the engine uses that no filing or captured file states directly. Status words:
VERIFIED, MEASURED, ASSUMED, OPEN (as in FUND_FACTS.md). Every ASSUMED value comes with a sensitivity. Change a
value only with a dated note that gives the reason.
